# Service guide: Public computers

Document ID: SVC-04

Public computers are available on a first-come, first-served basis. Each session lasts up to 60 minutes when other patrons are waiting. Patrons must save their work to their own storage before logging out. The library cannot guarantee that files left on a public computer will be retained.

This guide describes the fictional Fairview Public Library used for the assignment demonstration. For live changes or account-specific requests, contact staff.
