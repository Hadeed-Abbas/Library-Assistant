# Service guide: Events and reading groups

Document ID: SVC-08

The library publishes a monthly calendar of reading groups, children’s story sessions, and author talks. Registration may be required for events with limited seating. Event times can change, so patrons should confirm the latest calendar with the service desk. The assistant does not register attendees.

This guide describes the fictional Fairview Public Library used for the assignment demonstration. For live changes or account-specific requests, contact staff.
