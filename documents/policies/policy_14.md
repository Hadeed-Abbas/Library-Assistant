# Policy: Returns and book drop

Document ID: POL-14

Borrowed books may be returned at the circulation desk during opening hours or in the external book drop when it is available. Items placed in the book drop are checked in when staff process the returns. Keep the return receipt if one is provided and contact staff if a return is not reflected on the account.

For exceptions or account-specific decisions, contact the Fairview Public Library circulation desk. This policy document is part of the fictional course dataset.
